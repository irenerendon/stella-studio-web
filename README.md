# 🌟 Stella Estudio - Plataforma Web Oficial

Bienvenida a la plataforma oficial de Stella Estudio.  
Este proyecto fue desarrollado como una solución moderna para la gestión de turnos y exhibición de servicios de barbería, peluquería y estética premium en CABA.

---

# 🏗️ Stack Tecnológico

El proyecto fue construido utilizando tecnologías modernas enfocadas en rendimiento, escalabilidad y experiencia de usuario.

## Frontend
- React 18
- TypeScript
- Vite

## Diseño y UI
- Tailwind CSS
- shadcn/ui
- Diseño responsive optimizado para móviles y desktop

## Funcionalidades
- Sistema de reserva de turnos por pasos
- Navegación dinámica
- Integración con WhatsApp
- Optimización SEO local para San Cristóbal, CABA

---

# 💎 Características Principales

## Smart Booking Flow
Sistema interactivo de reservas con selección guiada de servicios.

## SEO Local
Estructura optimizada para posicionamiento en búsquedas relacionadas con barbería y peluquería en CABA.

## Performance Optimization
Carga rápida y optimización de assets para mejorar la experiencia del usuario.

## Responsive Experience
Interfaz adaptable para celulares, tablets y escritorio.
